### Tesla Drive Engine
A specialized playback experience designed for Tesla's in-car browser environment.

Utilizes WebCodecs, Web Audio, and WebAssembly-based audio decoding to support media playback within supported vehicle browsers.

Supports:
- Cloud-hosted media sources.
- Library management.
- Cross-device synchronization.
- Remote session monitoring.
